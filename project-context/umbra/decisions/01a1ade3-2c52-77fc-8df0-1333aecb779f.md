All "easier for older people" changes branch on `AppTheme.senior == UmbraFlavor.isLight`: bigger text scale, higher-contrast tokens, taller controls, labelled buttons, "about" text and quick actions (lib/theme/app_theme.dart:174; grep of all branches) [100]. `AppSettings` has no accessibility field (lib/data/models.dart:187-261) [80]. So classic users cannot opt in and Novčanik users cannot opt out. Novčanik also hides "For them" everywhere (lib/screens/shell_screen.dart:129 and others) [80]. The intent is recorded in the 726e195 commit message ("Make Novčanik easier for older people") [80]. Why it is tied to the flavor rather than a setting is not recorded; owner has not confirmed.
