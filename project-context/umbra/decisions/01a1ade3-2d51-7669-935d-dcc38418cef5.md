`lib/l10n/l10n.dart` is a const class. Each string is `t(en, srLatn)`; there is no ARB, gen-l10n or l10n.yaml (l10n.dart:6-19; ls) [100]. The locale comes only from the stored setting (default `en`); the device locale is never read (grep) [80]. Fiscal error messages (fiscal_receipt.dart:176-207) and notification texts (notifications_service.dart:51-86) are hard-coded English. The notification channel name ('Umbra reminders', :53) and the weekly reminder body (:76) say "Umbra" in both flavors [80]. New user-facing strings go into L10n as `t(en, srLatn)` pairs. Observed in code at HEAD 726e195; the reason is not recorded and the owner has not confirmed it.
