In `lib/`, the only network code is `fetchFiscalReceipt`: one form POST of iic/dateTimeCreated/tin to `<origin>/ic/api/verifyInvoice`, with a 20 s timeout (lib/services/fiscal_receipt.dart:149-172; grep and MockClient probe) [100]. For a scanned QR, the origin comes from the QR. Any host ending in `tax.gov.me`, on any port, is accepted (fiscal_receipt.dart:36-63; probe) [100]. A photo whose recognised text holds IKOF, PIB and a date posts to `mapr.tax.gov.me` with no user confirmation (lib/screens/scan_screen.dart:149-156; probe) [100]. On web, Flutter's CanvasKit and mobile_scanner's zxing-wasm also load from CDNs (package source, not run) [80]. Verified at HEAD 726e195.
