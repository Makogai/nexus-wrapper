The app is distributed as sideloaded APKs (README.md:22) [80]; no store listing is inferred [50]. Settings tells users to install each new APK over the app and never uninstall, because uninstalling erases every receipt and there is no cloud account (lib/screens/settings_screen.dart:248; lib/l10n/l10n.dart:259-261) [80]. Release APKs are signed with the debug key (android/app/build.gradle.kts:41-51) [80], so only an APK signed with the same debug keystore (normally the build machine's) can upgrade an install (inferred from Android's signature check) [50]. Build outputs are app-classic-release.apk / app-light-release.apk, not the app-release.apk the README names [100]. Verified at HEAD 726e195.
