All amounts are `double`, with no minor units (lib/data/models.dart:22-24,124,201,205,277) [80]. Stored amounts are non-negative, and the sign comes from `EntryType` (ledger_controller.dart:242,413,453) [80]. Display rounding is in `formatMoney` via `toStringAsFixed(2)`. Amounts saved from AddEntryScreen are usually whole cents, because prefilled and computed fields are rounded with `moneyInput`; typed values are not (inferred) [50]. Sums of stored doubles still carry float noise such as `1.2000000000000028` (lib/services/money.dart:3-31; balance_timeline.dart:79; probe) [100]. `parseAmount('1.234')` is 1.234, and `'1.234.567'` is null (money.dart:33-48; probe) [100].
