The Android flavor sets only Android-side resources: app id, label, launcher icon and two colours (android/app/build.gradle.kts:29-39; android/app/src/light/res/values*/colors.xml) [80]. The Novčanik Dart experience comes only from `lib/main_light.dart:5`, which sets `UmbraFlavor.isLight = true`. Nothing reads `appFlavor` or a dart-define for it (grep) [80]. So `--flavor light` alone gives an app labelled Novčanik that runs classic Umbra and its database (inferred) [50]. The repo never documents this pairing (grep; README.md:11-28) [100]. Local build state suggests the last light release used `-t lib/main_light.dart` [50]. Verified at HEAD 726e195; grades: 100 executed, 80 read at source, 50 derived.
