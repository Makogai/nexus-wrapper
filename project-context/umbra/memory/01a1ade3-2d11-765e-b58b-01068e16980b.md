`_postDueRecurring` runs only in `load()`, `addRecurring` and `updateRecurring`. There is no timer or lifecycle hook (lib/state/ledger_controller.dart:37,419,429; grep) [80]. It back-fills every due month since `createdAt`, at 09:00 on the clamped day. It dedupes by `recurringId` + year/month among current entries only (lib/services/recurring.dart:9-46; probe) [100]. Inferred: deleting an auto-posted entry makes it reappear on the next launch, and re-enabling an item back-fills all missed months [50]. Also: `settings.monthlyIncome` is never posted or added to the balance; it is only a fallback in the monthly review (review_engine.dart:243-244) [80]. Verified at HEAD 726e195.
