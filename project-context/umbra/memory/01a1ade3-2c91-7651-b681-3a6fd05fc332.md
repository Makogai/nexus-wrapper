Four string-keyed stores: `entries`, `recurring`, `settings` (record `'app'`), `price_links` (record `'links'`) (lib/data/app_database.dart:10-16) [80]. There is no version, no migration and no transactions (grep) [100]. Enums decode with `values.byName`, and `loadEntries` has no try (lib/data/models.dart:170,174; app_database.dart:43) [80]. So an unknown enum value or a corrupt row throws during `createLedger()`, and `boot()` has no guard (lib/main.dart:24-29) [80]. Inferred: the app would not start [50]. Any model change needs tolerant `fromMap` defaults. Verified at HEAD 726e195.
