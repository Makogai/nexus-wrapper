## Problem
- Creating a listing auto-approves it for every user type, both with photos (`processing` → `ListingPublishCoordinator`) and without (`SellerListingController`).
- The manual "publish" action in the web (`SellerListingController::publish`) and the API (`SellerListingApiController` line ~248) auto-approves only when `user.type === 'private'`. Dealers (`dealer_employee`) land in `pending_review`.
- The rule has been there since the first "Alpha v1" commit (`ffd813b`, 2026-06-05), so it is not a later deliberate change.

## Decision (recommended in the learning pass; confirm with the product owner)
- Use one policy for every publish path: auto-approve with moderation afterwards, the same as create. Keep the stricter `ListingAutoPublishEvaluator` only for Autodiler imports.
- Rationale: dealers are the more trusted sellers, so reviewing only them is inverted. Two rules for the same action confuse sellers.
- Put the rule in one place, a service method used by both controllers, instead of the inline `type === 'private'` checks.
