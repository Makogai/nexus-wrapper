## What it is

- A vehicle marketplace: one Laravel 12 app serves the public website, the seller dashboard, the staff admin panel and a JSON API *(verified: composer.json, bootstrap/app.php)*.
- The website uses Inertia v3 + Vue 3.5 + Tailwind v4, built with Vite 7, with an SSR entry point *(verified: package.json, vite.config.js)*. The admin panel is Filament 5 at `/admin` *(verified: composer.json)*.
- The `/api/v1` API serves the separate Flutter app (`drivebay-flutter`, its own repo, out of scope here) *(verified: routes/api.php; CLAUDE.md)*.
- Two brands are built from the same code at deploy time: `drivebay` and `autoklik` *(verified: config/brands/)*.
- Target market is Montenegro and the wider Balkans: English and Serbian locales, a Montenegro fuel-price feed, and an import from the Autodiler marketplace *(verified: lang/en, lang/sr, SyncMontenegroFuelPricesCommand, app/Services/Autodiler; market focus inferred)*.

## Who uses it

- **Buyers:** browse, search, save searches, favourite, compare, message sellers, book viewings and test drives *(verified: routes/web.php)*.
- **Private sellers and dealers:** create and promote listings, view analytics, manage viewing slots; dealers also get a storefront on a subdomain or custom domain, plus reviews *(verified: routes/web.php, routes/storefront.php)*.
- **Staff:** `super_admin`, `admin` and `moderator` roles (Spatie Permission). They moderate in Filament and directly on listing pages *(verified: HandleInertiaRequests.php, routes/web.php)*.
- **Mobile app users,** through the API *(verified: routes/api/v1/)*.

## Main features

- Listing lifecycle: draft → publish or moderate → sold, archived or rejected *(verified: app/Domains/Listing/Services/ListingService.php)*.
- Search through Scout + Meilisearch over a separate `listing_search_documents` table *(verified: composer.json `search:setup`)*.
- Rule-based recommendations, rebuilt every night, plus an optional weekly email digest *(verified: routes/console.php)*.
- Payments for promotions through a pluggable gateway: Fake, Stripe or Paddle *(verified: app/Domains/Billing/Gateways)*.
- Social login with Google, Facebook and Apple *(verified: config/services.php, bootstrap/app.php)*.
- Instagram and Facebook publishing of listings, plus a public `/instagram` gallery *(verified: app/Domains/SocialPublishing/Publishers, routes/web.php)*.
- Push notifications through Firebase, alongside in-app notifications *(verified: composer.json kreait/laravel-firebase; details MAIW)*.
- Tools: fuel prices, a fuel-consumption calculator (with an OpenAI estimate), a registration-cost calculator *(verified: routes/web.php, FuelEconomy/Services/OpenAiFuelConsumptionClient.php)*.
- Advertising slots, engagement pop-up campaigns, analytics, an SEO sitemap and OG images *(verified: routes/web.php)*.
- 15 Pennant feature flags *(verified: app/Features/)*.

## How to run and test

NEXUS's map lists only `npm run dev`/`npm run build`. The real entry points are Composer scripts *(verified: composer.json)*:

| Purpose | Command |
|---|---|
| First setup (installs, starts Docker, migrates, seeds, builds) | `composer run setup` |
| Infrastructure (Postgres 16, Meilisearch 1.12, Redis 7, Mailpit) | `composer run docker:up` / `docker:down` / `docker:fresh` |
| Develop (serve + `queue:listen` + Vite + Inertia SSR) | `composer run dev` |
| Re-sync the search index | `composer run search:setup` |
| Regenerate the OpenAPI file | `composer run api:docs` |
| Tests | `php artisan test --compact` (Pest 4) |
| PHP formatting | `vendor/bin/pint --dirty` *(AGENTS.md)* |

- Tests run on SQLite in memory with a `sync` queue *(verified: phpunit.xml)*. CI runs on PHP 8.4, then `npm ci && npm run build` *(verified: .github/workflows/tests.yml)*.
- Locally, Herd serves `https://drivebay.test` while Docker provides the services. The admin seed login is in README.md.
