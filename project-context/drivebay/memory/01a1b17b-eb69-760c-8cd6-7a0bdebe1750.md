## Components

- **One Laravel 12 app with domain modules.** Business logic lives in 21 domains under `app/Domains/{Domain}/` (Listing, Vehicle, Moderation, Media, Search, Recommendation, Dealer, Billing, Viewing, Messaging, User, Geography, Experiment, Notification, Engagement, Analytics, Promotion, SocialPublishing, Advertising, FuelPricing, FuelEconomy) *(verified: ls app/Domains)*. Eloquent models sit in a parallel tree, `app/Models/Domains/{Domain}/Models/` *(verified)*. Controllers in `app/Http/Controllers/{Web,Api/V1,Admin}` should stay thin *(CLAUDE.md; the rule itself not audited)*.
- **Three route groups,** wired in `bootstrap/app.php` *(verified)*:
  - `routes/web.php`: the Inertia marketplace and seller dashboard. The marketplace routes are registered twice: without a prefix (English) and under `/sr` with route names prefixed `sr.`. `/en/*` redirects with a 301 to the unprefixed URL *(verified: routes/web.php)*.
  - `routes/storefront.php`: dealer storefront pages, guarded by `storefront.host` *(verified)*.
  - `routes/api.php` → `routes/api/v1/*.php`: 11 files (auth, catalog, analytics, campaigns, engagement, seller, dealer, viewing, fuel-prices, tools, moderation) *(verified)*.
- **Middleware pipeline.**
  - `ResolveDealerStorefrontHost` runs first on every web request. `SetLocale`, `EnsureEngagementVisitor` and `HandleInertiaRequests` run last. The API adds `SetApiLocale` *(verified: bootstrap/app.php)*.
  - Aliases: `staff`, `verified`, `can.create.listings`, `storefront.host`, `marketplace.host`, `sanctum.optional`, `profile.complete` *(verified)*.
- **Admin:** Filament 5 with 32 resources in `app/Filament/Admin/Resources` *(verified: count)*.
- **Frontend:** Inertia pages in `resources/js/Pages`, plus `Components`, `Layouts` and `composables`, and an SSR entry `resources/js/ssr.js` *(verified)*.
  - Every page receives shared props: `auth` (including staff role and capabilities), `flash`, `locale`, `locales` (en, sr) and the full translation tables passed through `brandify()` *(verified: HandleInertiaRequests.php)*.
- **Cross-cutting helpers,** autoloaded globally *(verified: composer.json `files`)*:
  - `brand()` reads `config/brand` (packs in `config/brands/drivebay.php` and `autoklik.php`). `brandify()` replaces `:app` in strings.
  - `platform_config($key)` returns admin-overridable settings declared in `config/platform_config.php`. Boolean keys resolve through a Pennant flag in global scope; other keys use a stored override, falling back to config *(verified: app/Support/Settings/PlatformConfigService.php)*.
- **Background work:** Horizon with two supervisors and the Laravel scheduler (see "Data flow").

## Data flow

1. **Listing lifecycle** *(verified: ListingService.php)*:
   - `createDraft(CreateListingDTO)` → `update` → `publish($autoApprove)` or a staff `approve`.
   - Publishing fires the `ListingPublished` event and queues `SyncListingSearchDocumentJob`. Updates also re-sync the search document.
   - `markAsSold` queues `UpdateInstagramSoldCaptionJob`. `reject` and `archive` close the listing.
2. **Search:** the denormalised `listing_search_documents` table is indexed into Meilisearch through Scout. `composer run search:setup` syncs the index settings, then imports `ListingSearchDocument` *(verified: composer.json)*.
3. **Scheduled pipeline** *(verified: routes/console.php)*:

   | When | What |
   |---|---|
   | Daily 03:00 → 03:15 → 03:30 → 04:00 | Recommendations: listing similarity → scores → user profiles → candidates |
   | Weekly | Recommendation digest email, only if `recommendations.digest.enabled` |
   | Hourly | Saved-search alerts, viewing appointments, promotion expiry |
   | Daily | Account purge 02:30, Montenegro fuel prices 07:00, Instagram token warning 09:00 |
   | Weekly, Sunday 02:00 | mobile.de taxonomy import (queued) |

   Most entries use `withoutOverlapping()->onOneServer()`, so they need a cache store that supports locks, such as Redis *(inferred)*.
4. **Payments:** `PaymentGatewayInterface` has three gateways: Fake, Stripe and Paddle *(verified: Billing/Gateways)*.
   - Webhooks: `POST /webhooks/stripe` and `/webhooks/paddle`. Both are exempt from CSRF, as is the Apple Sign-In callback *(verified: routes/web.php, bootstrap/app.php)*.
   - Paddle also has a client-side completion endpoint, `/billing/paddle-checkout/complete` *(verified)*.
5. **Errors:** on the web, 403/404/500/503 render the Inertia `Error` page (500 only when debug is off) and 419 redirects back with a flash message. API and JSON requests get the raw response *(verified: bootstrap/app.php)*.

## Key decisions

- **A modular monolith by domain,** designed so it can move to services later *(verified: docs/architecture/system-overview.md)*.
- **Brands are packs chosen at deploy time** (`BRAND=drivebay|autoklik`), not an admin CMS *(MAIW decisions; packs verified in config/brands)*.
- **Locale lives in the URL:** English has no prefix and Serbian is `/sr` *(verified: routes/web.php)*.
- **Long Autodiler imports run on their own queue:** the `redis-imports` connection, the `autodiler-imports` queue and the `supervisor-imports` supervisor. Timeouts are ordered job 900 s < supervisor 960 s < `retry_after` 1200 s (KAN-7). The default queue keeps a 60 s supervisor timeout and a 90 s `retry_after` *(verified: config/queue.php, config/horizon.php, app/Jobs/ImportAutodilerListingsJob.php)*.
- **Image processing is custom (Intervention Image).** Spatie Media Library was removed (KAN-16) *(verified: no medialibrary in composer.json; MAIW)*.
- **Paddle is a third gateway,** not Laravel Cashier *(MAIW decisions; gateway verified)*.
- **Spatie roles are the source of truth for staff access** (KAN-58) *(MAIW; roles in the shared props verified)*.
- **Vehicle taxonomy is seeded from a committed snapshot,** not from live API calls *(CLAUDE.md)*.
