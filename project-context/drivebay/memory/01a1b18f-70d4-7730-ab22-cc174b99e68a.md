# DriveBay — overview (draft v2, replaces v1)

Markers: *(verified: file)* = seen in the code; *(inferred)* = my conclusion; *(MAIW)* = from `D:\code\maiw\memory\drivebay`, not re-checked.

## What it is

- A vehicle marketplace. One Laravel 12 app serves the public website, the seller dashboard, the staff admin panel and a JSON API *(verified: composer.json, bootstrap/app.php)*.
- **Web:** Inertia v3 + Vue 3.5 + Tailwind v4 (Vite 7, with an SSR entry). **Admin:** Filament 5 at `/admin` *(verified: package.json, vite.config.js, composer.json)*.
- `/api/v1` serves the separate Flutter app (`drivebay-flutter`, its own repo, not covered here) *(verified: routes/api.php)*.
- Two brands come from the same code at deploy time: `drivebay` and `autoklik` *(verified: config/brands/)*.
- Market: Montenegro and the Balkans. There are English and Serbian locales, a Montenegro fuel-price feed and an Autodiler import *(verified: lang/, FuelPricing, app/Services/Autodiler; market inferred)*.

## Who uses it

- **Buyers:** search, save searches, favourite, compare, message sellers, book viewings and test drives *(verified: routes/web.php)*.
- **Sellers:**
  - User types include `private` and `dealer_employee` *(verified: User domain)*.
  - All sellers create, promote and analyse listings.
  - Dealers also get storefronts on a subdomain or custom domain, and reviews *(verified: routes)*.
- **Staff:** `super_admin`, `admin` and `moderator` roles. They use Filament and moderate inline on listing pages. Only `super_admin` sees the Artisan and developer-tools pages *(verified: HandleInertiaRequests, Filament pages)*.
- **Mobile app users,** through the API.

## Main features

- **Listing lifecycle:** draft → processing (photos) → active or pending_review → sold, archived or rejected. Most listings publish straight away and staff moderate afterwards *(verified: ListingService; policy inferred)*.
- **Search:** Meilisearch through Scout. **Recommendations:** rule-based scoring rebuilt every night, plus an optional weekly digest *(verified: config/scout.php, config/recommendations.php, routes/console.php)*.
- **Promotions** paid through Fake, Stripe or Paddle *(verified: Billing/Gateways)*.
- **Social login:** Google, Facebook, Apple. **Instagram and Facebook publishing**, plus a public `/instagram` gallery *(verified)*.
- **Notifications:** Firebase push alongside in-app notifications *(verified: composer.json; details MAIW)*.
- **Tools:** fuel prices, a fuel-consumption calculator (with an OpenAI estimate), a registration-cost calculator *(verified)*.
- **Also:** ads, engagement pop-up campaigns, analytics, sitemap and OG images, and 15 Pennant flags *(verified)*.

## How to run and test

NEXUS's map lists only `npm run dev`/`npm run build`. The real entry points are Composer scripts *(verified: composer.json)*:

| Purpose | Command |
|---|---|
| First setup | `composer run setup` |
| Infrastructure (Postgres 16, Meilisearch 1.12, Redis 7, Mailpit) | `composer run docker:up` / `docker:down` / `docker:fresh` |
| Develop (serve + `queue:listen` + Vite + SSR) | `composer run dev` |
| Re-sync the search index | `composer run search:setup` |
| Regenerate OpenAPI | `composer run api:docs` |
| Tests (Pest 4) | `php artisan test --compact` |
| PHP formatting | `vendor/bin/pint --dirty` |

- Tests run on SQLite in memory with a sync queue. CI uses PHP 8.4, then `npm ci && npm run build` *(verified: phpunit.xml, .github/workflows/tests.yml)*.
- Herd serves `https://drivebay.test` and Docker provides the services. The admin seed login is in README.md.
- Configuration is through environment variables read in `config/`; `.env.example` is blocked by Nortal's org-managed deny rule *(verified: grep of env() calls)*.
