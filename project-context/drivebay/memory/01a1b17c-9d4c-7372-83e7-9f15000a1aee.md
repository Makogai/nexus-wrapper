`routes/web.php` defines the marketplace routes in a closure, `$registerMarketplaceRoutes`, and mounts it twice:

- once at `/`, for English;
- once under `Route::prefix('sr')->as('sr.')`.

`/en` and `/en/*` redirect with a 301 to the unprefixed path.

Consequences:
- A route added inside the closure automatically exists in both locales. Its Serbian route name is prefixed `sr.`.
- Routes outside the closure do not get a `/sr` twin unless you add one. These include the webhooks, `/billing/paddle-checkout`, the OG images, `sitemap.xml`, `.well-known/*` and the admin watermark preview.
  - Example: `engagement/{campaign}/interact` is duplicated by hand, as `sr.engagement.interact`.
- The API sets its locale with the `SetApiLocale` middleware (the `Accept-Language` header), not through the URL.

(verified: routes/web.php, bootstrap/app.php)
