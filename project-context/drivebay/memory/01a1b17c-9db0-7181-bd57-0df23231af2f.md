Every scheduled task is in `routes/console.php`:

| When | Task |
|---|---|
| Daily 03:00 | `ComputeListingSimilarityJob` |
| Daily 03:15 | `ComputeListingRecommendationScoresJob` |
| Daily 03:30 | `RefreshRecommendationProfileJob` |
| Daily 04:00 | `BuildRecommendationCandidatesJob` |
| Weekly | `SendRecommendationDigestsJob`, day and time from `config/recommendations.php`; runs only if `recommendations.digest.enabled` |
| Hourly | `search:send-saved-search-alerts`, `viewing:process-appointments`, `ExpireListingPromotionsJob` |
| Daily 02:30 | `account:purge-deleted` |
| Sunday 02:00 | `vehicles:import-mobile-de --queue` |
| Daily 07:00 | `SyncMontenegroFuelPricesJob` |
| Daily 09:00 | `WarnExpiringInstagramTokenJob` |

To rebuild recommendations by hand: `php artisan recommendations:rebuild [--user=]` (runs synchronously).

Production runs the scheduler either as a Coolify cron entry (`* * * * * php artisan schedule:run`, see the header comment in `docker-compose.coolify.yml`) or as the Dockerfile's scheduler target, a 60-second loop.

(verified: routes/console.php, Dockerfile, docker-compose.coolify.yml)
