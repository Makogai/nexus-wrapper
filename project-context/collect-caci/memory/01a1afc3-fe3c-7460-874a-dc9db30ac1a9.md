# Collect Your Ćaci: architecture

## Components
- **API** (`backend/`). Node 22, Express 5, ESM, raw SQL through `pg`, zod validation *(verified: backend/package.json)*. `src/index.js` mounts 8 routers: auth, oauth, cacis, admin (only when enabled), stats, social, games, store. It also has one error handler that maps `HttpError` to `{error, ...extra}` and hides 5xx details *(verified: backend/src/index.js)*. Business rules live in `src/services/` (scoring, economy, duplicates, similarity, headcut, moderation, verification) *(verified: directory listing)*.
- **Database**. Postgres 17 with `pg_trgm`. At startup `migrate()` applies `backend/migrations/NNN_*.sql` in filename order, each file in its own transaction, and tracks them in `schema_migrations`. It then syncs the opštine list from `src/data/opstine.js` *(verified: backend/src/db.js)*.
- **App** (`app/`). Flutter for Android, iOS and web; `provider` + `ChangeNotifier` *(verified: app/pubspec.yaml, app/lib/main.dart)*. `Session` is the hub: auth token in SharedPreferences, meta cache, and the `caciChanges` / `feedVersion` notifiers that keep lists in sync *(verified: app/lib/session.dart)*. Graphify ranks it the most connected node (86 edges) *(verified: GRAPH_REPORT.md)*. The biggest module is the maze game (`maze/cacilend_screen.dart`, ~1650 lines) *(verified: wc)*.
- **Web image**. `flutter build web` served by nginx, which proxies `/api` to the API *(per CLAUDE.md; not opened)*.
- **Admin panel** (`admin/`). React 19, Vite, TanStack Query; it calls the API through a local `/api` proxy *(verified: admin/package.json, admin/vite.config.ts)*.
- **Tools** (`tools/*.py`). Generate sounds, the icon constants, the map JSON and the app icon *(per CLAUDE.md)*.

## Data flow
1. The app sends JSON (or multipart for images) with `Authorization: Bearer <JWT>`. The base URL comes from `--dart-define=API_URL`; without it, web uses `<origin>/api` and Android uses `10.0.2.2:3000` *(verified: app/lib/api.dart)*.
2. `requireAuth` verifies the JWT (30-day expiry) and sets `req.userId` *(verified: backend/src/auth.js)*.
3. Adding a ćaci goes through `POST /cacis/check` (cheap pre-check), then `POST /cacis`, which runs:
   - a cooldown check;
   - the 10-per-day limit;
   - dHash and CLIP embedding, then duplicate matching (409, or `needsConfirmation`);
   - storing the image;
   - in one transaction: claim the cooldown atomically, insert, and book +5 indeksi;
   - queueing the head cutout in the background *(verified: routes/cacis.js)*.
4. Voting runs in one transaction: lock the ćaci row (`FOR UPDATE`), upsert or delete the vote, apply delta counters, pay the "good eye" reward when it flips to fake, and pay the vote reward *(verified: routes/cacis.js)*. `is_fake` is a generated column *(per CLAUDE.md)*.
5. Every ćaci payload comes from `caciSelect()`, with `$1` = the viewer. This is what gives every row the same shape and its `my_vote` *(verified: routes/cacis.js)*.
6. Money moves only through `book(db, user, amount, reason, key)`: a ledger row with `ON CONFLICT (user_id, key) DO NOTHING`, then a balance update. A one-off key therefore never pays twice *(verified: services/economy.js)*.

## Boundaries and integrations
- **OpenAI**: optional. Moderation, plus image edits for the photo mode, which is closed *(per CLAUDE.md; images.js not opened)*.
- **Local ML**: CLIP via `@huggingface/transformers` (q8). It loads in the background at startup, the model is cached in the `models` volume, and older caricatures are back-filled *(verified: services/similarity.js, index.js)*. The head detector and cutout models are in `services/headcut.js` *(per CLAUDE.md)*.
- **SMTP** (nodemailer) for verification codes *(verified: package.json; mail.js not opened)*.
- **OAuth** with Google, Facebook and Apple: server-side code flow, hidden unless keys are set *(per CLAUDE.md, CHANGELOG)*.
- **Deploy**: Coolify (Dockerfile build pack, Traefik, `trust proxy` 1) *(verified: index.js, docs/DEPLOY.md)*. Cloudflare sits in front of the web app, with cache-busting `?v=<md5>` *(per CHANGELOG 2026-11-05)*.

## Key decisions
- Raw SQL with denormalized counters kept in sync inside `withTx` *(verified: db.js, cacis.js)*.
- Real photos are never stored, and there is no face recognition. A duplicate is refused only when name, age and image all agree *(verified: cacis.js comments; per CLAUDE.md)*.
- Game scores are client-reported, bounded by zod maxima and daily wallet caps *(verified: routes/games.js, economy.js)*.
- The admin API is mounted only when `APP_ENV=development` or `ADMIN_ENABLED`, and `requireAdmin` re-reads `is_admin` on every request *(verified: config.js, auth.js)*.
- In production, startup fails if `DATABASE_URL` or a strong `JWT_SECRET` is missing *(verified: config.js `assertProductionConfig`)*.

## Risks and open questions
- No automated tests or CI. The only safety nets are `flutter analyze` and manual smoke tests *(verified)*.
- JWTs are valid for 30 days with no revocation, and `requireAuth` doesn't check that the user still exists *(verified: auth.js)*.
- The admin panel targets the **beta API by default**, so local admin edits change live data *(verified: admin/vite.config.ts)*.
- A ćaci's `report_count` counts toward hiding at 5 reports, but there is no review UI *(verified: cacis.js; per CLAUDE.md)*.
- Startup keeps CLIP and the head models in memory (~400 MB RAM according to DEPLOY.md) *(inferred: needs a server with 2 GB+)*.
- Not reviewed: `oauth.js`, `admin.js` internals, `headcut.js`, most app screens *(inferred gaps)*.
