Places where the docs no longer match the code. Trust the code:
- CLAUDE.md layout says `lib/map/serbia_map.dart` loads `assets/map/serbia.json`. The real files are `app/lib/map/region_map.dart` (`RegionMap`, `MapRegion`) and `app/assets/map/map.json` (verified).
- README "Prepoznavanje duplikata" describes the old rule (trigram ≥ 0.55 + age ±3 refuses). The code refuses only when name ≥ `MATCH_NAME` (default 0.6), age ±3 **and** CLIP ≥ `MATCH_IMAGE_SAME` (0.9) all agree (verified: config.js, services/duplicates.js). CLAUDE.md is correct.
- CLAUDE.md "Open ideas" lists removing Android `usesCleartextTraffic`. That flag is only in `android/app/src/debug/AndroidManifest.xml`, so release builds are already HTTPS-only (verified).
- CLAUDE.md says "Locally ... demo / caci1234 is an admin". In fact `seed.js` makes `demo` an admin on **every** seeded database, the beta included (verified: seed.js:136).
- CLAUDE.md "Moderation UI for reported cacis" is listed as not done. The admin dashboard already lists reported cacis and offers `POST /admin/cacis/:id/dismiss-reports` (verified: routes/admin.js), so a basic version exists.
- API routes the app never calls: GET `/games/ride/:caciId`, GET `/stats/overview`, `/store` and buy/equip (store closed), and the `zemlja` feed/top filter (verified by grepping app/lib).
