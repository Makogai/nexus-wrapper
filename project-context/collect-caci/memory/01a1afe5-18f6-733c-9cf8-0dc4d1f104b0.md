backend/src/index.js mounts `statsRouter`, `socialRouter`, `gamesRouter` and `storeRouter` all at `/`, in that order (verified). `routes/stats.js` declares the public `/meta/opstine`, `/meta/caricature-prompt` and `/meta/config` first, then calls `router.use(requireAuth)` (verified). Because routers mounted at `/` see every request that hasn't been answered yet, that middleware also runs for every request headed to social, games, store and the 404 handler *(inferred from Express semantics)*.

Consequences:
- A new public endpoint added to social.js, games.js or store.js would still demand a token.
- An unauthenticated request to an unknown path gets 401, not 404.

Put new public routes in stats.js above `router.use(requireAuth)`, or in a router mounted before statsRouter. `/auth` and `/cacis` are mounted separately; cacis applies `requireAuth` to everything (verified: routes/cacis.js).
