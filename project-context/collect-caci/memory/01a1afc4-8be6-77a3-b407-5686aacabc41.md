`throw new HttpError(status, 'Serbian message', extra)` (backend/src/auth.js). The handler in backend/src/index.js responds `{ error: message, ...extra }`. 5xx errors are replaced by "Nešto je puklo na serveru." unless `err.expose` is set, and multer's `LIMIT_FILE_SIZE` becomes a 413 (verified: index.js).

The app relies on these extra fields, which come back on `ApiException.body` (app/lib/api.dart). Examples:
- 429 `next_caci_at` (cooldown);
- 409 `existing` / `possible` / `needsConfirmation` (duplicate flow in routes/cacis.js);
- 403 `needs_verification` (email verification, per CLAUDE.md).

If you rename one of these keys, update the Flutter screen that reads it. zod failures from `parse()` come back as 400 with the text `<field>: <message>` (verified: auth.js).
