# Collect Your Ćaci: overview (v3, full read)

## What it is
A satirical social game for a Serbian audience. Players ("studenti", the good guys) "catch" Ćaci, caricatures of people they see as pro-government loyalists, tagged with name, age and opština. The crowd votes plus or minus *(verified: CLAUDE.md, routes/cacis.js)*. Score per ćaci is 10 + plus − minus, or −50 once it's stamped "NIJE ĆACI" (5+ minuses and at least twice as many minuses as pluses; it's reversible) *(verified: services/scoring.js, migrations/001_init.sql)*. The UI is in Serbian (Latin script); code and commits are English; the README and changelog are Serbian *(verified)*.

## Who uses it
- Players on Android, iOS and the web: one Flutter app *(verified: app/pubspec.yaml)*.
- Two developers (Marko, gale_091), each with their own Claude, handing work over through `docs/CHANGELOG.md` *(verified)*.
- Admins, through a local-only React panel that talks to the beta API by default *(verified: admin/vite.config.ts, docker-compose.yml)*.

## Main features
- **Catching.** Upload a caricature made in ChatGPT from one of 50 prompt variants. One per hour and 10 a day. Duplicates are detected by name trigram, a local CLIP image embedding and age; refused only when all three agree *(verified: routes/cacis.js, services/duplicates.js, prompts.js)*.
- **Social.** Votes, one-level threaded comments with likes and @mentions, two-layer comment moderation, reports (hidden after 5), friends and friend requests, user search and profiles *(verified: routes/cacis.js, social.js, services/moderation.js)*.
- **Rankings** by collector (all or friends), by ćaci and by opština, plus a zoomable map of Serbia (Kosovo included), Montenegro and Republika Srpska *(verified: routes/stats.js, map/region_map.dart)*.
- **Indeksi economy.** A ledger with one-off keys, daily caps on Belgrade time, 12 levels, 15 achievements, a store (closed) *(verified: services/economy.js, levels.js, achievements.js, store.js)*.
- **Mini games** with client-reported scores:
  - "Jahanje Ćacija": city runner or field side-scroller, with the ćaci's cut-out head as the rider. Super Ćaci need level 4.
  - Ćacilend: a Pac-Man-like maze where ćaci heads chase you.
  *(verified: routes/games.js, ride/, maze/)*
- **Accounts.** Username and password with an emailed 6-digit code. Google, Facebook and Apple are coded but hidden without keys *(verified: routes/auth.js, oauth.js)*.
- **Polish.** Light and dark theme, synthesized sound effects and music, Phosphor icons *(verified: theme.dart, sound.dart, music.dart)*.

## How to run and test
- `docker compose up -d --build` starts db (:5433), api (:3000), web (:8080) and admin (:8081, pointed at the beta unless `ADMIN_API_TARGET=http://api:3000`) *(verified: docker-compose.yml)*.
- `cd app && flutter run -d chrome --dart-define=API_URL=http://localhost:3000` gives hot reload; VS Code has launch configs for Chrome, Android and iOS *(verified: README, .vscode/launch.json)*.
- Backend scripts: `npm run make-admin <user> [--revoke]`, `regen-placeholders`, `test-cacis [-- --remove]`, `seed` *(verified: backend/package.json)*.
- Checks: `flutter analyze` (must be clean), plus the curl smoke test from CLAUDE.md. **There are no automated tests and no CI** *(verified)*.

## Status and gaps
- Public beta on Coolify (API caci.mrh.lol, web behind Cloudflare), seeded with demo data *(verified: admin/vite.config.ts; per CHANGELOG and DEPLOY.md)*.
- **Urgent:** `POST /auth/verify` gives out tokens for verified accounts without checking the code, and the seed makes `demo` an admin on the beta. Tracked in its own NEXUS task *(verified: routes/auth.js, seed.js)*.
- Open: no rate limiting, push notifications, password reset, profile editing, a production domain, or a reopened store. Reports have only a basic admin review (dashboard list plus "dismiss reports") *(verified: admin.js; CLAUDE.md)*.
- Switched off but still in the code: the photo-to-AI and placeholder catch modes, the store, social login *(verified)*.
