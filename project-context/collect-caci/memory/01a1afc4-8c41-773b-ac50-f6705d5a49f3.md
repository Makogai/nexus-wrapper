The beta web app (caci-web.mrh.lol) sits behind Cloudflare. Cloudflare rewrites Cache-Control to `max-age=14400` (Browser Cache TTL), even though `app/docker/nginx.conf` sends `no-cache`. To get around it, `app/docker/Dockerfile` appends `?v=<md5 of main.dart.js>` to `flutter_bootstrap.js` (in index.html) and to `main.dart.js` (mainJsPath) after the build. index.html itself is not cached, so every deploy loads the new files without a purge (per docs/CHANGELOG.md 2026-11-05; Dockerfile not opened in the learning pass).

If a deployed web build looks like the previous commit, check that this rewrite still runs before purging Cloudflare. Compare the commit in the API's `/health` `version` field (from SOURCE_COMMIT; verified: backend/src/index.js, config.js).
