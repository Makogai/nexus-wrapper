Every indeksi change goes through `book(db, userId, amount, reason, key)` in `backend/src/services/economy.js`. Call it inside an open `withTx` transaction. A non-null `key` makes the entry one-off: `INSERT ... ON CONFLICT (user_id, key) DO NOTHING`, and the call returns 0 when nothing was booked. Key format is `<reason>:<id>`, for example `catch:<caciId>`, `vote:<caciId>`, `good_eye:<caciId>` (verified: economy.js, routes/cacis.js).

Pitfall: daily caps don't all use the same window.
- Wallet caps (vote, ride, maze, daily visit) count the **Belgrade calendar day** (`TODAY_SQL = (now() AT TIME ZONE 'Europe/Belgrade')::date`) (verified: economy.js).
- The 10-ćaci-per-day limit is a **rolling 24 h** (`created_at > now() - interval '1 day'`) (verified: routes/cacis.js POST /).

Amounts live only in `EARN`. The app gets them from `/meta/config.earn_rules`, so don't hard-code them in the app (verified: EARN_RULES in economy.js).
